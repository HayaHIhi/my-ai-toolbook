# My AI toolbook

A one-page personal reference for the AI tools I’m learning, and the projects I build with them. Built as an assignment for the AI for Engineering course.

- **Live site:** https://hayahihi.github.io/my-ai-toolbook/
- **Repository:** https://github.com/HayaHIhi/my-ai-toolbook

## What’s inside

- **Toolkit:** every tool I’ve learned, with its source and status (in use or exploring), what it is, and my tips.
- **Projects:** what I built with these tools.
- **About this site** and **About the developer.**

## How to run it

Open `index.html` in a browser. There is nothing to install.

## How to add content

Open `index.html`, find the block marked `EDIT HERE`, and add an entry to `TOOLS` or `PROJECTS`.

## How it was built

Plain HTML, CSS and JavaScript in a single file, hosted on GitHub Pages. The first version was drafted with Claude; I refined it and published it from VS Code. `AGENTS.md` holds the project rules for AI agents working on the site.
